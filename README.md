# T.C. Çay Demliği Çalışma ve Sosyal Güvenlik Bakanlığı

Bu depo, çay demliğini bir işçi, kaynamayı mesai, posayı sendika başkanı kabul eden **resmî** bir kamu kurumudur.

Anlam aramayın. Sicil numarası arayın.

## Ne yapar?

`bakanlik.py` çalıştığında:

1. Rastgele bir demliği kadroya çağırır.
2. Mesai süresini hesaplar.
3. Sendika kararı tebliğ eder.
4. Mühürler.
5. Çayı içmez. Çünkü çay artık dosyadır.

## Kurulum ve çalıştırma

```bash
python3 bakanlik.py
```

Bağımlılık yoktur. Sadece Python 3 ve biraz fazla ciddiyet yeter.

## Yasal uyarı

- Limon eklemek toplu sözleşme ihlalidir.
- Posa çöpe atılamaz; arşivlenir.
- İtiraz yoktur. Çay soğur.
